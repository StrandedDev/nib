# nib v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build nib v1 as `SPEC.md` describes it: a nano-style terminal editor that never loses a file, shipped as deb/rpm/tar/msi/zip with installers.

**Architecture:** A library crate (`src/lib.rs`) holds all logic in small modules, and `src/main.rs` stays thin (args → `App::run`). Pure logic (buffer, file I/O, editing, undo, layout, find, keymap, config) has no terminal dependency and is unit-tested headless. Only `terminal.rs` and `render.rs` touch crossterm output. Every user action is a `CommandId` in one registry (`commands.rs`), and both the keymap and the palette read from it.

**Tech Stack:** Rust 2024 (MSRV 1.85), crossterm 0.29, ropey 1.6, arboard 3.7, base64, toml, serde, dirs, unicode-segmentation, unicode-width, anyhow; tempfile (dev).

**Spec:** `SPEC.md` (behaviour source of truth) · `AGENTS.md` (process rules).

## Global Constraints

- Done means all three pass: `cargo fmt --check` · `cargo clippy --all-targets -- -D warnings` · `cargo test`.
- Binaries land in `./target` (set in `.cargo/config.toml`).
- `unsafe_code = "forbid"`. No new crates unless a task says so, with a size/need note in `Cargo.toml`.
- Every disk-write path goes through `fileio::atomic_write` and has a `tempfile` test.
- Every exit path, panics included, restores raw mode and the main screen.
- Every user action is a `CommandId`; no key is handled outside the registry, except text input and prompt input.
- Colours: 16 ANSI colours only (`crossterm::style::Color::{Black..White, DarkGrey..}`), never RGB/256.
- UTF-8 only. Keep the BOM, the line ending (LF/CRLF), and the final newline. New files: LF + final newline.
- Title right side: `YYYY-MM-DD HH:MM` (clean) | `Modified` | `New File`, plus ` [Read-only]` when not writable.
- Large file threshold: 50 MB (`50 * 1024 * 1024` bytes).
- Commits: plain imperative, no co-author trailers, no AI/tool attribution. Feature work on a branch off `main`.
- When behaviour differs from SPEC.md, update SPEC.md in the same commit.

## Review Focus

1. **Mixed line endings** (a CRLF file with a few stray LF lines). Expect the majority ending to be kept, and save never doubles `\r`. Test: Task 1.2 `mixed_endings_use_majority_and_roundtrip`.
2. **One huge line** (5 MB minified JSON, no newlines). Expect render and cursor moves to stay fast, and layout only touches the visible rows. Test: Task 2.3 `layout_long_line_only_visible_rows`.
3. **Windows paths with colon** (`C:\notes\x.md`, `C:\x.md:12`). Expect the drive colon never to parse as a line number. Test: Task 1.4 `drive_letter_not_line_suffix`.
4. **Grapheme at wrap edge** (a ZWJ emoji or CJK char that does not fit the last column). Expect it to move whole to the next row, and the cursor never to land inside a cluster. Test: Task 2.3 `wide_grapheme_wraps_whole`.
5. **Save fails mid-write** (disk full, or no permission on the dir). Expect the original bytes unchanged, no temp file left, and the buffer still dirty. Test: Task 1.3 `failed_write_leaves_original_and_no_temp`.

### Task 1.3: File read + atomic write

**Files:** Create `src/fileio.rs`

**Interfaces:**
- Produces:
  ```rust
  pub enum Loaded { Text(Buffer), NotFound, Directory, Binary, TooLarge(u64) }
  pub fn load(path: &Path, allow_large: bool) -> io::Result<Loaded>;
  pub fn atomic_write(path: &Path, bytes: &[u8]) -> io::Result<()>;
  pub fn mtime(path: &Path) -> Option<SystemTime>;
  pub fn is_writable(path: &Path) -> bool;   // file exists: open for write; else parent dir
  pub fn format_mtime(t: SystemTime) -> String; // "YYYY-MM-DD HH:MM", local time
  ```
- Binary = NUL byte in the first 8192 bytes **or** invalid UTF-8 anywhere.
- `atomic_write`: resolve symlinks with `fs::canonicalize` (if the target exists), then temp file `.<name>.nib-<pid>.tmp` in the same dir → write → `sync_all` → copy permissions from the original → `fs::rename`. On Unix, also `fsync` the dir. On any error, remove the temp and return the error. Keep the owner on Unix by `chown`-ing the temp to the original uid/gid when it differs (`std::os::unix::fs::chown`, ignore EPERM).
- Local time: `std` has no time-zone support, and `unsafe` is forbidden. **Decision:** add crate `jiff` with `default-features = false, features = ["std", "tz-system"]`. Justification for `Cargo.toml`: about 300 KB, and it gives correct local time + DST on Linux and Windows. Confirm this crate with the user before adding it.

- [ ] Tests (tempdir): `load_text`, `load_missing_is_notfound`, `load_dir`, `load_nul_is_binary`, `load_bad_utf8_is_binary`, `load_large_needs_flag` (write a sparse 51 MB file with `set_len`), `atomic_write_replaces_content`, `atomic_write_follows_symlink` (unix-only `#[cfg(unix)]`: link stays a link, target has new bytes), `atomic_write_keeps_mode` (unix: 0o640 kept), `failed_write_leaves_original_and_no_temp` (target dir made read-only on unix / target path is an existing dir on all OSes → `Err`, original bytes same, no `*.nib-*.tmp` left), `format_mtime_shape` (matches `^\d{4}-\d{2}-\d{2} \d{2}:\d{2}$`).
- [ ] Implement.
- [ ] Run checks. Commit `Add file loading and atomic save`.

**Files:** Create `src/layout.rs`

**Interfaces:**
- Produces:
  ```rust

  pub fn rows_for_line(line: &str, line_idx: usize, width: u16, wrap: bool) -> Vec<Row>;
  ```

## Phase 4 — Navigation and palette

### Task 4.1: Find + replace
**Files:** Create `src/find.rs` · Modify `src/app.rs`, `src/render.rs`
- `pub fn find_all(rope: &Rope, query: &str) -> Vec<Range<usize>>`. Smart case: case-insensitive unless the query has an uppercase char. Simple per-char lowercase compare, no regex. Incremental: every keystroke in the find prompt reruns the search and jumps to the first match at or after the cursor. Enter = next, Shift+Enter = prev, Esc = cancel and restore the cursor. Matches are highlighted (current one in reverse, the others underlined). Wrap around, with status `Search wrapped`.
- Replace: prompt `Find:` → `Replace with:` → per match the Choice `(R)eplace / (A)ll / (S)kip / Esc`. Replace-all is one undo step.
- Tests: `smart_case_lower_insensitive`, `smart_case_upper_sensitive`, `multibyte_match_ranges`, `next_wraps`, `replace_all_one_undo`, `skip_leaves_match`.
- Commit `Add incremental find and replace`.

### Task 4.2: Go to line, Open, Save As, toggles
**Files:** Modify `src/app.rs`

## Phase 5 — Safety extras

### Task 5.1: Recovery file + PID lock
**Files:** Create `src/recovery.rs` · Modify `src/app.rs`
- Location: `dirs::data_local_dir()/nib/recovery/<fnv1a64(canonical path) as 16 hex>.rec`. Unnamed buffers use `untitled-<pid>.rec`. Format: line 1 `nib-recovery 1`, line 2 `pid <n>`, line 3 `path <utf8 path>`, line 4 empty, then the `Buffer::to_bytes()` payload. Written through `atomic_write` every 3 s while dirty. Deleted on clean save and on clean quit.
- Lock = a recovery file (or an empty `.lock` sibling with the same header when clean) whose PID is alive. PID alive check: Unix `kill -0` equivalent via `/proc/<pid>` existence (Linux only, per SPEC platforms). Windows: `OpenProcess` needs unsafe/windows-sys, so **decision:** run `tasklist /FI "PID eq N" /NH` and look for the PID in the output. Slow but only runs on open.
- On open: lock alive → prompt `already open in another nib (pid N) — open read-only? (Y/n)`. A stale recovery file exists → prompt `Recover unsaved changes from <time>? (Y/n)`. Yes loads the payload as a dirty buffer.
- Tests: `recovery_roundtrip`, `stale_pid_offers_recovery`, `live_pid_offers_read_only` (uses the current PID), `clean_save_removes_recovery`, `path_hash_stable` (fixed vector for FNV-1a: `fnv1a64(b"") == 0xcbf29ce484222325`).
